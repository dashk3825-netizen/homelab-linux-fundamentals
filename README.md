# Linux Home Lab

## Overview
This project documents my self directed Linux Home Lab built using Oracle Virtual Box and Ubuntu Desktop. The purpose is to build practical Linux, networking, and systems administration skills as a foundation for cloud computing and cybersecurity.

## Technologies Used
- Oracle Virtual Box
- Ubuntu Desktop 26.04 LTS
- Linux Terminal
- GitHub

## Skills Learned 
- Linux command-line navigation
- File management
- File permissions
- Package managaement
- Basic networking
- Virtual machine management
- Linux troubleshooting

## Repository Structure 
- Notes.md - contains my lab notes and trouble shooting
- Screenshots/ - Screenshots from each lab session
